### Ejercicio 1

Transforme los siguientes métodos de Java a funciones equivalentes en Scala:

#### Método 1
```java
double calcularAreaTriangulo(double base, double altura)  {
   double area = (base * altura) / 2;
   return area;
}
```

#### Método 2
```java
double celsiusAFahrenheit(double celsius) {
	double fahrenheit = celsius * 9 / 5 + 32;
	fahrenheit = Math.round(fahrenheit * 100.0) / 100.0;
	return fahrenheit;
}
```

#### Método 3
```java
double calcularVolumenCilindro(double radio, double altura) {
	double volumen = Math.PI * Math.pow(radio, 2) * altura;
	return volumen;
}
```

#### Método 4
```java
double calcularInteresCompuesto(double capital, double tasa, int periodos) {
    double monto = capital * Math.pow(1 + tasa, periodos);
    return monto;
}
```



### Funciones matemáticas como código

Debe definir una función en Scala por cada una de las siguientes funciones matemáticas. El símbolo ∑ representa sumatoria y ∏ representa productoria, más adelante encontrará un ejemplo.

> Por cada problema escriba los tres primeros términos que genera la función, los anota en una hoja junto con la función. Debe tener claro cómo y qué términos generan las funciones.

### Función 1

```math
f(n) = \sum_{i=1}^{n} 2i

```

Tres primeros términos: 2+4+6

Solución:
```scala
def f1(n: Int) = (1 to n).map(i => 2 * i).sum
```

### Función 2

### Función 5

La suma de las primeras \( n \) potencias de una razón \( r \), cada una multiplicada por una constante \( a \):

